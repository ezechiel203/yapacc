# Shell completions

No completion file is kept in the source tree: they are generated by the
binary itself, so they always match its command grammar.

```sh
yapacc completions bash   > yapacc        # /usr/share/bash-completion/completions/yapacc
yapacc completions zsh    > _yapacc       # /usr/share/zsh/site-functions/_yapacc
yapacc completions fish   > yapacc.fish   # /usr/share/fish/vendor_completions.d/yapacc.fish
```

`elvish` and `powershell` are accepted too. For one user, without root:

```sh
yapacc completions bash > ~/.local/share/bash-completion/completions/yapacc
yapacc completions fish > ~/.config/fish/completions/yapacc.fish
```

The packages in [`../packaging/`](../packaging/README.md) and the release
archives generate and install the bash, zsh and fish files at build time.
