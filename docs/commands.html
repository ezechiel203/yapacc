Handbook · Reference

Every command

yapacc --help lists the everyday commands. This page lists all of them, including the specialist ones it leaves out. yapacc help COMMAND prints the options of any command, and yapacc docs carries longer built-in topics.

Commands marked read-only change nothing. Commands marked gated show a plan and stop at the gate.

names§

yapacc names NAME says what a package is called on other distributions. It asks repology.org, which means it sends the name you give to that site. It needs curl, and exits with code 6 without it.

Other sources§

These commands install software that does not come from the distribution's repositories. Each one records what it installed in yapacc's ledger, so that it can be listed, audited and removed later. Native packages are never recorded there.

CommandWhat it does
flatpak list|search|inforead flatpak
install flatpak, remove flatpak, update flatpakmanage flatpaks (gated)
install appimage, remove appimage, update appimagemanage AppImages under your home directory (gated)
install foreign, remove foreign, update foreignunpack a package made for another distribution into an isolated directory, without touching the system (gated)
foreign info|listinspect such a package, list the isolated installs
external list|audit, remove externaleverything the ledger tracks
ledger status|list|head|verify|audit|conflictsread the ledger and check its hash chain
sources apt|rpmread APT or RPM source definitions
pluginslist adapter programs that add sources
repair LOGclassify a failed build or install log and suggest repairs
fixes list|push|pullkeep recorded repairs, and share them through a git remote you configure

Isolated installs are described in ISOLATED_INSTALLS.md.

Scheduled checks§

On Arch, yapacc monitor check is a one-shot check for pending updates, meant for a timer, and yapacc monitor daemon-install installs a systemd timer that runs it (gated). Nothing of the kind is installed unless you run that command: see rule 2 in the introduction. On other systems both exit with code 6; use yapacc check from your own timer there.

Global options§

OptionEffect
--jsonmachine-readable output on read commands
--scriptnever prompt; fail fast
--noconfirmconsent in advance, like --yes on a gated command
--config PATHuse this configuration file
-V, --versionprint the version

Global options go before the command: yapacc --json why bash.

Gated commands take --dryrun (plan only) and --yes (apply without asking) after the command: yapacc upgrade --dryrun.
