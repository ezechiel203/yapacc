# Fonts

The website bundles three typefaces, each under the SIL Open Font License,
version 1.1. The licence texts are beside the files, as the licence asks.
The files are the Latin subsets of the variable fonts, as packaged by the
Fontsource project.

| File | Typeface | Copyright | Licence |
|---|---|---|---|
| `fraunces.woff2`, `fraunces-italic.woff2` | Fraunces | The Fraunces Project Authors | `OFL-Fraunces.txt` |
| `source-serif.woff2`, `source-serif-italic.woff2` | Source Serif 4 | Adobe | `OFL-SourceSerif.txt` |
| `jetbrains-mono.woff2` | JetBrains Mono | The JetBrains Mono Project Authors | `OFL-JetBrainsMono.txt` |
